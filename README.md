# 🏠 Smart 2BHK Home – Cisco Packet Tracer

## 📌 Project Overview

The **Smart 2BHK Home**
project is a home automation and smart home networking simulation created using **Cisco Packet Tracer**. It represents a two-bedroom, hall, and kitchen (2BHK) home and demonstrates the concept of integrating smart devices into a residential environment.

The project aims to explore how networking and IoT technologies can be used to build a connected home environment.

## 🎯 Objectives

- Design a simulated smart 2BHK home environment.
- Explore IoT-based home automation using Cisco Packet Tracer.
- Understand the connectivity between smart devices and network components.
- Demonstrate how smart home devices can be integrated into a single environment.
- Develop practical knowledge of smart home networking and automation concepts.

## 🛠️ Tools & Technologies

- **Cisco Packet Tracer** – Network and IoT simulation
- **Internet of Things (IoT)** – Smart device integration
- **Home Networking** – Connectivity between devices

## 🚀 How to Run

1. Download the `.pkt` file from this repository.
2. Install and open Cisco Packet Tracer.
3. Open the downloaded project file.
4. Explore the home layout, connected devices, and network configuration.
5. If device interactions or automation rules are configured, test them within the simulation.
